## 1. 평가 범위와 방법

- **샘플**: 15건 · 13개 분야 (선정 기준: 설계 문서 §4). 모두 Requests+BeautifulSoup 로 본문 추출 성공(15/15).
- **비교 대상**
  - 대본: `script_v1.md`(개선 전: 단일 프롬프트, 분석·규칙·자동 수정 없음) vs `script_v2.md`(개선 후: STEP 02 분석 결과 주입 + 길이·형식·근거·이미지 규칙 + 자동 검사 1회 수정)
  - 그림체: `marker_mono_v1`(개선 전: 구성안의 `style_prompt` 한 줄) vs `marker_mono`(개선 후: 구체적 화풍 문구 + 반복 시각 요소 + 흑백 후처리)
- **모델**: 대본 생성·심사 모두 EXAONE `k-exaone_v2.5`(reasoning_effort=low), 이미지 OpenAI `gpt-image-2`(medium, 1024×1536)
- **채점**: 자동 지표(길이·형식·근거 일치율, 이미지 지표) + LLM 심사 5항목(1~5점). 심사 프롬프트는 `pipeline/eval/judge.py`
- **짝지은 비교**: 두 버전 모두 성공한 샘플끼리만 평균을 냈다(대본 9건, 그림체 3건).

### 평가가 다 끝나지 않은 부분 (그대로 밝힘)
- 대본 평가 30건 중 **9건이 EXAONE 일일 호출 한도(100회/일)에 걸려 실패**했다:
  law-jeonse/v2, law-jeonse2/v2, pet-sep/v2, review-cafe/v1·v2, self-pomo/v1·v2, travel-jeju/v1·v2.
  한도가 풀린 뒤 `wbs-eval script --resume eval/runs/20261110-0855-script` 로 이어서 채운다.
- 그림체 비교는 비용·시간을 고려해 우선 3건(경제 2, 재테크 1)으로 했다.

## 2. 대본 품질 (짝지은 9건)

| 지표 | v1 (전) | v2 (후) | 변화 |
|---|---|---|---|
| 길이 30~60초 통과율 | 0% | 100% | +100%p |
| 예상 길이 (초) | 155.4 | 50.1 | −105 |
| 형식 위반 (건/편) | 11.1 | 0.3 | −10.8 |
| 근거 확인 장면 비율 | 43.7% | 91.1% | +47.4%p |
| 정확성 (1~5) | 4.22 | 4.22 | 0 |
| 왜곡 지적 (건/편) | 1.00 | 0.56 | −0.44 |
| 자연스러움 (1~5) | 3.89 | 4.11 | +0.22 |
| 구조 (1~5) | 4.11 | 3.89 | −0.22 |
| 핵심 포함 (1~5) | 3.56 | 2.56 | −1.00 |
| 그림 설명력 (1~5) | 4.44 | 3.56 | −0.89 |
| 심사 평균 (1~5) | 4.04 | 3.67 | −0.38 |
| 생성 시간 (초/편) | 60 | 258 | +197 |

### 해석
1. **v1 은 영상 대본으로 쓸 수 없다.** 평균 155초(목표의 2.5~5배), 형식 위반 편당 11건이다. 길이 제한이 없으니 원문을 많이 옮겨
   심사의 '핵심 포함'·'그림 설명력' 점수가 높게 나온 것으로, **심사 평균(4.04)만 보면 v1 이 낫다고 오해하기 쉽다.**
   심사 점수는 길이·형식 통과 여부와 함께 읽어야 한다.
2. **v2 는 사실성이 좋아졌다.** 근거 확인 장면이 2배, 왜곡 지적이 절반이다. 남은 왜곡 사례는 조건부 문장을 일반화한 경우
   (예: "변동금리 대출이 1%p 오르면…"을 가정 예시가 아닌 일반 사실처럼 말함, econ-rate)로, 숫자 자체가 틀린 경우는 지적되지 않았다.
3. **v2 의 약점: 핵심 누락.** 50초 안에 넣으려다 원문의 중요한 조건·항목을 빠뜨린다
   (fin-isa: 손익통산·금융소득종합과세 제외 누락 / tax-yearend: 공제 항목 대부분 생략).
4. **v2 의 약점: 그림 지시가 막연해짐.** 화풍 단어 금지·글자 필요한 대상 금지 규칙 때문에 image_prompt 가 일반적인 사물 나열로 흐른다
   (it-python 4장면: "자료구조와 함수·모듈을 충분히 설명하지 못함").
5. **생성 시간 4배.** 분석(1회) + 생성(1회) + 자동 수정(대개 1회)으로 호출이 3배이고, EXAONE 은 low 에서도 추론 토큰이 많다
   (테스트 1편: 3회 호출 · 추론 토큰 22,518 · 13분).

### 다음 개선(v3) 계획
| 문제 | 프롬프트 변경 | 확인 지표 |
|---|---|---|
| 핵심 누락 | STEP 02 의 `key_points` 를 번호로 주고, 각 장면이 어느 key_point 를 다루는지 `covers` 필드로 밝히게 함. 빠진 key_point 가 있으면 자동 검사가 지적 | 핵심 포함 ≥ 3.5, `covers` 누락 0 |
| 길이 안에서 정보 밀도 | 장면 수를 4~8 중 key_point 수에 맞춰 고르게 허용, 장면당 한 생각 유지 | 길이 통과율 100% 유지 |
| 그림 설명력 | image_prompt 를 "주체 + 행동/변화 + 비교 대상" 형식으로 강제(예: "a coin rolling from a bank toward a house, arrow showing direction") | 그림 설명력 ≥ 4.0 |
| 생성 시간 | 분석과 대본을 한 번에 요청하는 모드, 또는 LLM_PROVIDER=openai 비교 | 편당 ≤ 120초 |

## 3. 그림체 일관성 (짝지은 3건 · 30장)

| 지표 | 전 (`marker_mono_v1`) | 후 (`marker_mono`) |
|---|---|---|
| 일관성 점수 | 76% | **95%** |
| 장면 간 선 굵기 변동(CV) | 0.183 | **0.089** |
| 장면 간 복잡도 변동(CV) | 0.223 | **0.186** |
| 회색·음영 비율 | 0.255 | **0.183** |
| 채도 | 0.6 | **0** |
| 글자 영역 비율 (CRAFT, 참고) | 0.033 | **0.004** |
| 통과율: 음영 적음 | 33% | 67% |
| 통과율: 그림 속 글자 거의 없음 | 0% | 100% |

### 해석
- **개선 전 그림에는 영어 글자와 원문에 없는 달러 금액이 들어갔다** ("DAILY NEWS", "CENTRAL BANK", "$25", "$2.50" 등).
  한국 원화 금리 글에 달러 가격이 그려진 것은 그림체 문제이자 **사실 왜곡**이다. 개선 후에는 글자가 거의 사라졌다.
- 이 차이는 처음 정한 지표(선 굵기·채도·배경)로는 잡히지 않아, 평가 중에 **글자 영역 지표를 추가**했다(드로잉 엔진에 포함된 CRAFT 텍스트 검출).
  - 한계: 달력 칸·동전 무늬를 글자로 잡는 오탐이 있어(개선 후 장면 최대 0.0185) 장면 단위 판정에는 쓰지 않고 작업 평균만 본다.
  - 개선 후에도 econ-fomc 1장면에 캐릭터 이름표 "Neogulman" 글자가 남았다 → 스타일 문구에 "no name tags, labels or signs" 추가 필요.
- 음영 기준(0.25 이하) 통과율이 67%로, 개선 후에도 안티에일리어싱·잔선 때문에 경계에 걸리는 장면이 있다. 흑백 후처리 임계값 조정 후보.

- 무료 플랜에서 쓸 수 있는 목소리는 기본(premade) 21종으로 모두 영어 원어민이지만, multilingual 모델로 한국어를 읽으면 받아쓰기 기준 발음은 정확했다.
  억양의 자연스러움은 사람이 들어보고 판단해야 한다(미평가).
- **기본 목소리 21개 선정 평가** (원자료 `eval/voice_bench_elevenlabs_premade.json`)
  - 방법: 숫자·전문용어가 섞인 문장 2개를 읽게 하고 OpenAI 받아쓰기로 2회씩 채점(숫자 표기 25% ↔ 이십오 퍼센트 차이는 무시), 말 속도 측정
  - 첫 채점에서 점수가 0.906·0.926 으로 몰렸는데, 원인은 발음이 아니라 받아쓰기가 숫자를 "25%"로 적는 표기 차이였다 → 채점 방식을 고쳐 재평가.
    받아쓰기 결과도 실행마다 달라(같은 음성이 한 번은 100%, 한 번은 "전세→전에") 1회 채점은 믿기 어렵다.
  - 결과: 8개 목소리가 4회 모두 100%. 대본 길이 규칙(6.1자/초 기준)에 가장 가까운 속도를 기준으로 **Alice(6.5자/초, "Clear, Engaging Educator")** 선정, 예비 Brian(6.92자/초).
    가장 빠른 목소리(Jessica 8.28자/초)는 짧은 대본에서 30초 미만이 될 위험이 있다.
- 한국어 원어민 목소리(Voice Library·professional)는 유료 플랜이 필요하다. 기업 결과물로 쓰려면 상업적 이용 조건도 유료 플랜 기준으로 확인해야 한다.

### 대본 AI 기본값 변경: EXAONE → OpenAI `gpt-4.1-mini`

같은 파이프라인·같은 v2 프롬프트로 law-jeonse(EXAONE 평가에서 일일 한도로 미완료된 샘플)를 STEP 01~03 실행.

| 항목 | EXAONE `k-exaone_v2.5` (low) | OpenAI `gpt-4.1-mini` |
|---|---|---|
| STEP 01~03 시간 | 약 13분 (test-cafe, 3회 호출) | **15.6초** (3회 호출) |
| 토큰 | 입력 6,559 · 출력 24,596 (추론 22,518) | 입력 7,917 · 출력 1,797 |
| 비용 | 미확인 (단가 비공개) | **$0.006** |
| 호출 한도 | 초당 1회 · 하루 100회 | 무료 등급 기준 일 수십 회(계정 등급에 따라 다름) |
| 결과 | 길이·형식 통과 | 길이(예상 44~54초)·형식 통과 |

- **새로 발견한 문제**: gpt-4.1-mini 는 v2 의 "글자가 필요한 대상은 고르지 않는다" 규칙을 지키지 않고
  `document labeled '등기부등본'`, `ID cards labeled '집주인'` 같은 **그림 속 한글 글자 지시**를 넣었다.
- **대응**: 자동 검사에 `image_prompt_text` 항목(한글·labeled·written·따옴표 등)을 추가 → 1회 수정 요청으로 5장면 모두 글자 없는 그림 지시로 바뀌고 경고 0건.
